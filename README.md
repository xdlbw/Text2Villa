# Text2Villa

Official project repository for **Text2Villa: Hierarchical Generation of 3D Indoor Environments with Physics-Aware Analysis-by-Synthesis**.

Text2Villa generates multi-story, polygonal 3D indoor environments from natural-language descriptions and refines asset placement with an affordance-driven physical-semantic scene graph and a physics-aware closed-loop solver.

Authors: Xiang Tang, Ruotong Li, and Xiaopeng Fan.

The project website is maintained on the `project_page` branch. Paper and code links will be added when they are public.
